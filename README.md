# Flutter Multi-Tool App

A multi page Flutter application that combines three smaller apps I created into one project. The app uses navigation to let users switch between a to-do list, counter, and BMI calculator from one interface.

This project helped me practice organizing multiple features within one Flutter application instead of building each one separately.

## Features

### To-Do List

* Add tasks to a daily task list
* View added tasks
* Manage tasks through a simple interface

### Counter

* Increase and decrease a counter
* Updates the displayed value as the user interacts with it

### BMI Calculator

* Enter information used to calculate BMI
* Calculates and displays the BMI result

## Multi Page Navigation

The three apps are combined into one Flutter project with navigation between:

* **Todo**
* **Counter**
* **BMI**

This allowed me to practice working with multiple screens and organizing different features inside the same application.

## Technologies Used

* Flutter
* Dart
* Flutter Web
* Material Design

## How to Run

1. Make sure Flutter is installed.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Install the project dependencies:

```bash
flutter pub get
```

5. Run the web version in Chrome:

```bash
flutter run -d chrome
```
